## 5. 事务语义

- Half Message + END_TRANSACTION commit/rollback；
- check-back（code 39）与超时回滚；
- Half WAL / retry WAL / delay WAL / 审计 JSONL；
- 幂等生产 `(topic, msgId)`；
- 人工 `POST /tx/{id}/commit|rollback`；
- TC：openraft 单节点 + 三节点 TCP + 状态 WAL + 持久化 log + 快照/压缩；
- Broker↔TC 多地址 + 持久化 outbox + 按 TC 决策收口；
- 消费 Inbox（显式调用）；
- **不承诺端到端 exactly-once**：自动 Inbox/分布式去重未完成。

## 6. 未完成（不能宣称 1.0）

1. 5 万+ TPS（当前 100k 长跑 9,347；批量 64 条 24,982）。
2. Docker/K8s 实测（宿主无 Docker/WSL）。
3. HA：异步/同步 ack + 路由/epoch/事件栅栏；无 Raft 共识、无多数派、无逐条精确 ack。
4. TLS/gRPC/消息轨迹；ACL group/IP 权限与热更新。
5. Inbox 自动拦截/分布式去重表。
6. CQ 无分段/增量清理；Retention 丢弃时全量重写 CQ。
7. Tag 首次订阅偶发超时（R60 复测 5/5，根因未定位）。

## 7. 结论

MQ-rust 已达到**可运行、可复现验收的单机事务消息中间件**水平；TC 具备三进程 TCP Raft、failover、持久化与快照压缩。  
距离生产 1.0 的性能、HA、容器实测与安全目标仍有明确差距，项目目标未全部达成，goal 保持 active。
