## 4. 在有运行时的环境中的验收步骤

```powershell
# 1. 安装 Docker Desktop（WSL2 后端）或 Podman
# 2. 构建
docker build -f deploy/Dockerfile -t mq-rust:0.9.0-rc.1 .
# 3. 启动
docker compose -f deploy/docker-compose.yml up -d
# 4. SDK 验收
java -cp "tests/compat/out;<rocketmq-lib>" MqRustCompatSmoke 127.0.0.1:9877 MQ_DOCKER
# 5. K8s
kubectl apply -f deploy/k8s/mq-rust.yaml
kubectl get pods,svc,pvc
```

## 5. 结论

容器化是 1.0 的硬性缺口；当前只能声明“容器资产已准备、未实测”。
