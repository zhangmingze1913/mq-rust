## 4. 已验证能力

- 普通/顺序/事务/定时/批量/死信；
- 重试、Inbox 幂等、SQL92 Push；
- 事务超时回滚、check-back、重启恢复；
- Retention、CommitLog 回收、双分片、quorum + failover + fence；
- mqadmin 主要命令、轨迹持久化与查询。

## 5. 未达标（不可宣称 1.0）

1. 5 万 TPS：最佳 8,438；硬件/单写盘上限。
2. 容器化：宿主无 Docker/Podman/kubectl/WSL 发行版，清单未实测。
3. 严格 Raft：无任期/投票，依赖 quorum + fence。
4. TLS/gRPC、ACL group 权限。
5. CommitLog 仅整段删除；轨迹无轮转/分页。
6. SQL92 Pull 首心跳时序。

## 6. 建议下一步

- SSD/NVMe + 多分片 + 批量流水线压测 5 万；
- 在可用容器环境跑 compose/K8s 验收；
- 引入 Raft 选举与 TLS/mTLS；
- 轨迹轮转、精确段回收、group ACL。
