## 1. 5 万 TPS（P0）

**现状**

```text
单条 1M       8,438 TPS
batch64       24,982 msg/s
batch128      30,860 msg/s
batch256      37,095 峰值
原生 RocketMQ 15,465 TPS（同机）
```

**阻塞**

- 4 线程 / HDD；
- 单 CommitLog 写盘、fsync、单队列锁。

**工作项**

1. SSD/NVMe 上复测 batch128/256/512；
2. 2–4 分片 CommitLog + 独立写线程；
3. 多 broker 集群按队列分流；
4. 批量流水线合并 CommitLog 写。
5. 验收：1M × 256B ≥ 50,000 msg/s，失败 0，P99 < 100ms。

## 2. 严格 Raft 选举（P1）

**现状**：quorum 复制 + 先到先得提升 + fence，无任期/投票/日志多数派。

**工作项**

1. broker 元数据与 leader lease 入 openraft（TC 或 broker 内置）；
2. 任期/投票持久化、日志复制、快照；
3. 旧 leader 自动 fence；客户端路由切换；
4. 3 broker 故障注入：kill leader、网络分区、重启。
5. 验收：任一时刻至多一个可写 leader；已提交消息不丢。

## 3. TLS/gRPC（P2）

**工作项**

1. remoting TLS：rustls 服务端证书/私钥、客户端 CA；
2. Java SDK TLS 配置对照；
3. gRPC 管理/事务 API（tonic）；
4. mTLS、证书轮换。
5. 验收：Java SDK TLS 收发；未认证连接拒绝。
