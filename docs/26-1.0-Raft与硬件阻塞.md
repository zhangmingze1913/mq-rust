## 2. 性能

```text
非 Raft batch256   37,095 msg/s（验收值）
Raft 单节点        3.0–3.9k
Raft 3 副本        1.9–2.1k（4 并发）
Raft 3 副本 120s   226,816 / 0 失败
Raft 3 副本 300s   516,608 / 4 失败
```

Raft 同步提交路径无法达到 5 万；非 Raft 路径在现有 2C/4T + HDD 上也无法达到 5 万。

## 3. 仍未完成

- 5 万 TPS：需 ≥8 核/NVMe 或 2–4 broker 集群；
- 长跑 500s 尾段 3s 超时：主机 HDD I/O 饱和（非 Raft 对照 R207 也出现）；
- 快照仍全量序列化，建议改增量；
- 三副本 1M 长跑（最大 633k/500s）；
- 4 节点初始收发通过，但重加入复制未完成（R210）。
- 事务 commit 重复提交已验证幂等（R211）；
- CommitLog 段内精确回收。
