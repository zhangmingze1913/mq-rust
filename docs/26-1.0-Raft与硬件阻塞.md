## 2. 性能

```text
非 Raft batch256   37,095 msg/s（验收值）
Raft 单节点        3.0–3.9k
Raft 3 副本        1.9–2.1k（4 并发）
Raft 3 副本 120s   226,816 / 0 失败
Raft 3 副本 300s   516,608 / 4 失败
```

Raft 同步提交路径无法达到 5 万；非 Raft 路径在现有 2C/4T + HDD 上也无法达到 5 万。

## 3. 仍未完成

- 5 万 TPS：接受为硬件阻塞项关闭；四轮 K8s 实测峰值约 2.7k，需 ≥8 核/NVMe 多机；
- 三副本长跑尾段仍有约 0.6 次/秒超时（R222，540 次/900s）；
- CommitLog 离线与在线精确压缩已实现（R223/R226）；
- 快照支持有界尾部与全量模式（R224）；动态加节点设计见 [27-动态加节点设计](27-动态加节点设计.md)，未实现；
