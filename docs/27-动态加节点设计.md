# 动态加节点设计（未实现）

> 状态：设计稿；当前集群成员在启动时固定，动态 add/remove 未实现。

## 1. 目标

- 新 broker 空盘启动，加入现有 Raft group；
- 通过快照 + 日志追平；
- 成员变更走后端 Raft membership；
- 旧节点可安全移除。

## 2. 现有障碍

- `NetworkFactory.peers` 在启动时固定，无法感知新节点地址；
- `RaftNetworkV2::install_snapshot` 当前直接返回 `Unreachable`，新节点无法通过快照追平；
- `MessageSM` 仅有界/全量快照，未做分块传输；
- broker 静态 `--raft-peers`，没有 join API。

## 3. 设计

1. `peers` 改为 `Arc<RwLock<HashMap<u64,String>>>`；
2. 新增 Admin `POST /raft/add`（node_id, addr）：
   - 写入 peers；
   - `raft.add_learner(node_id, (), true)`；
   - `raft.change_membership(new_set, false)`；
3. 实现 `install_snapshot`：分块发送 snapshot bytes，接收端写入 `raft.snapshot`；
4. 新节点以 `--raft-join <seed>` 启动，不调用 initialize；
5. 移除节点：`change_membership` 去掉后停进程。

## 4. 验收

- 3 节点集群加入第 4 节点，追平后读写；
- kill 旧节点，集群仍可用；
- 新节点重启后 applied 水位正确。

## 5. 工作量

- 网络/快照传输：3–5 天；
- 成员变更/运维：2 天；
- 故障测试：2 天。
