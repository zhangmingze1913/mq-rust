# R118 · mqadmin 兼容增强（202/203）

> 日期：2026-11-25  
> 结果：`mqadmin topicStatus` 可用；`consumerConnection` 返回空连接表（无消费者时标准 206）。

---

## 1. 新增

| 请求码 | 命令 | 响应 |
|---|---|---|
| 202 | `GET_TOPIC_STATS_INFO` | `TopicStatsTable` JSON |
| 203 | `GET_CONSUMER_CONNECTION_LIST` | 空 `ConsumerConnection` |

202 的 `offsetTable` key 使用 JSON 对象字符串：

```json
{"topic":"MQ_ADMIN2","brokerName":"broker-a","queueId":3}
```

否则 fastjson 会把它当 MessageQueue bean 解析并报 `syntax error`。
