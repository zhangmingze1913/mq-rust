# R150 · 批量 128 性能

> 日期：2026-11-25  
> 结果：batch128 稳态约 **30,860 msg/s**，高于 batch64 的 24,982，但仍未达 5 万。

---

## 1. 配置

```text
BatchProducer -s 128 -b 128 -w 8
retain=500/1s，segment64MiB，queues8
```

## 2. 采样

```text
Send TPS 197  MPS 25241
Send TPS 195  MPS 24995
Send TPS 240  MPS 30806
Send TPS 241  MPS 30860
Send Failed 0
```

## 3. 对比

| 批量 | msg/s |
|---|---|
| 单条 256B | 8,438 |
| batch64 | 24,982 |
| batch128 | **30,860** |
| 目标 | 50,000 |

## 4. 结论

- 增大 batch 仍有收益，但边际递减；
- HDD 单写盘/4 核为瓶颈；
- 5 万需 SSD、更多分片/核心或集群。
