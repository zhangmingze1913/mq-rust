# R151 · 批量 256 性能

> 日期：2026-11-25  
> 结果：batch256 峰值 **37,095 msg/s**，稳态约 35,000，仍低于 5 万。

---

## 1. 配置

```text
BatchProducer -s 128 -b 256 -w 8
retain=500/1s，segment64MiB，queues8
```

## 2. 采样

```text
Send TPS 98  MPS 25098
Send TPS 144 MPS 37095
Send TPS 124 MPS 31778
Send TPS 136 MPS 35014
Send Failed 0
```

## 3. 对比

| 批量 | msg/s |
|---|---|
| 单条 | 8,438 |
| batch64 | 24,982 |
| batch128 | 30,860 |
| batch256 | **37,095 峰值 / ~35,000 稳态** |
| 目标 | 50,000 |

## 4. 结论

- batch 增大仍提升，但请求处理/CommitLog 写盘成为瓶颈；
- 5 万需 SSD、更多分片/核心或集群；
- 生产建议按业务批量上限设 128–256。
