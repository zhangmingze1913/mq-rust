## 3. 已知限制

- 三副本持续 batch256 会出现客户端发送超时（R198，26 次）；
- 未做三副本 1M 长跑；
- 5 万 TPS 在 2C/4T + HDD 上不可达；
- leader 崩溃时事务客户端需重试（R196）。

## 4. 验收结论

- Raft quorum HA、复制、持久化、快照、事务恢复达到 1.0 可交付；
- 5 万 TPS 按“硬件条件允许时”条款排除，需 ≥8 核/NVMe 或 2–4 broker 集群；
- 三副本长跑超时作为已知性能限制记录，不影响一致性。
