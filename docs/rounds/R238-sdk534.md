## 2. 修复的竞态

5.3.4 首次测试报：

```text
store error: raft applied message not found
```

原因：`raft.write` 返回后 apply 尚未把消息注册到 store，立即 `message_by_id` 可能 miss。
修复：`wait_applied` 最多 2s（5ms 轮询）等待 apply 可见；单发与批量路径都使用。
