# R258 · 批量 apply 等待优化

> 日期：2026-11-28  
> 结果：批量发送只等待最后一条消息可见，再逐条读取；减少 255 次轮询。60s 107,008/1,792、p50 145ms、p99 692ms。

---

## 1. 变更

批量 SEND：
- 先 `wait_applied(last_msg_id)` 一次；
- 然后对每条消息 `message_by_id` 读取；
- 不再为每条消息启动 5ms 轮询。

## 2. 60s

```text
2P/4C 60s: sent=107,008 failed=1,792 received=107,008
p50=145ms p99=692ms
```

## 3. 判断

- p50 145ms 为当前较优；
- 1,792 失败（约 1.7%）来自宿主/写入抖动；
- 优化减少轮询 CPU，但 60s 总吞吐提升不明显。
